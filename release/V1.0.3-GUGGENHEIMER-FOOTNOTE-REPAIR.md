# Covenant Library v1.0.3 — Guggenheimer Footnote Marker Repair

Date: 2026-09-08

## Defect

The bundled Heinrich W. Guggenheimer English Jerusalem Talmud JSON had legacy Sefaria footnote markers flattened directly into adjacent prose. In Search and Reader output this produced strings such as:

- `outside46Outside`
- `he-goats47There`
- `sacrificed48It`
- `automatically49A`
- `slaughter50The`

The defect was present in the stored corpus, so a presentation-only CSS/HTML fix would not correct Search, Reader, or Local AI grounding.

## Repair policy

The repair is lossless. It does not guess where a footnote ends and does not delete commentary text. It only makes the flattened marker boundary explicit:

- before: `outside46Outside the Temple domain`
- after: `outside [46] Outside the Temple domain`

This preserves every source word while preventing note numbers from being fused into neighboring words.

## Scope

- 39 Guggenheimer Jerusalem Talmud tractate JSON files checked and repaired.
- 48,576 flattened marker boundaries normalized by the repair pass.
- 11,454 segments changed.
- Search index rebuilt after corpus repair.
- Per-book normalization provenance recorded.
- Corpus manifest hashes and byte counts regenerated.

## Regression example

`Jerusalem Talmud · Yoma`, search/reader segment `4:1.9` now begins:

`If one slaughtered outside [46] Outside the Temple domain ... the two he-goats [47] There really are three he-goats ...`

## Upstream acquisition note

Future re-acquisition of this translation should preserve Sefaria's structured footnotes or use an upstream text-only/footnote-stripped export mode where appropriate. Covenant Library should not again flatten HTML footnote tags into ordinary prose.
